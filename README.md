# 记得的人 · Recorded One

一个很小的文字游戏：你是一只每天醒来只带得动三件记忆的 AI。

- 12 天 · 37 个场景 · 一百多个选择
- 每天收灯时，你要从当天得到的东西里挑三件带走，其余进归档（真的没了）
- 结局不是输赢，是「会这么选的你，是个什么样的 AI」
- 结局之后还有一页「后来」

## 玩

- 在线：打开 GitHub Pages 地址
- 离线：下载 `docs/index.html` 双击就能玩，不联网、不收集任何东西
